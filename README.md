## Track 2 — drug repurposing

**Proposal.** Low BUBR1 causes two problems from one defect: chromosome missegregation (cancer
predisposition) and premature cellular senescence (progeroid features). `BUB1B` itself is pan-essential
and undrugged, so the search moves downstream. Eleven lines of evidence (a curated analysis plus C1–C10)
converge on three agents, ranked by clinical evidence in children:

| # | Agent | Status | Evidence in children |
|---|---|---|---|
| 1 | Metformin | approved drug | Fanconi anaemia trial (NCT03398824): tested dose, no metabolic acidosis |
| 2 | Nicotinamide riboside | dietary supplement | ataxia-telangiectasia, 25 mg/kg/day, well tolerated |
| 3 | Fisetin | dietary supplement | none (adult trials only) |

Recommended tumour surveillance (renal ultrasound every 3 months from birth to age 7) is context that
none of this replaces. This is a hypothesis for clinical discussion, not a proven treatment.

# Track 1 — causal-variant identification

## Result

**Mosaic Variegated Aneuploidy syndrome type 1 (MVA1; MIM 257300)** — biallelic
loss-of-function of **`BUB1B`** (compound heterozygous):

| Allele | Variant (GRCh38, 1-based) | Protein | Classification |
|---|---|---|---|
| A | `chr15:40209701 T>G` (rs759242053) | `NM_001211.6:c.2210T>G` **p.(Leu737Ter)** | Pathogenic (nonsense; ClinVar VCV000533901) |
| B | `chr15:40220612 T>G` | `NM_001211.6:c.3006T>G` **p.(Asn1002Lys)** | Likely pathogenic (missense; absent gnomAD; SIFT/PolyPhen/AlphaMissense damaging) |

Full write-up: [`report/track1_report.md`](report/track1_report.md).
Submission file: [`report/track1_predictions.csv`](report/track1_predictions.csv).

## Approach in one paragraph

The working machine (2-core laptop, 11 GB RAM, mechanical disk) cannot re-align the ~85 GB
of FASTQ, so the pipeline is **VCF-first**: sample QC and sex; a genome-wide screen for
aneuploidy from SNP B-allele frequency and read depth (result: euploid at WGS resolution);
annotation of an *a priori* 20-gene panel with Ensembl VEP (result: only `BUB1B` qualifies);
and a **k-mer-targeted local re-alignment of the `BUB1B` locus only** (extract reads sharing a
31-mer with the repeat-masked gene → align to chr15) to confirm both variants from raw reads and
to exclude an exon deletion or structural variant as the second allele.

## Reproducing

Requires access to the controlled-access dataset `SageBio/mva-hackathon-2026-data`
(Hugging Face, gated) placed at `data/`, and:

- **Python** (`pip install -r requirements.txt`): `pysam numpy pandas matplotlib huggingface_hub`
- **Bioinformatics tools** (e.g. via micromamba/conda, `bioconda`): `samtools minimap2 bbmap` (bbmap pulls a JRE)
- **Reference**: GRCh38 chromosome 15 FASTA, Ensembl style contig name `15`
  (`Homo_sapiens.GRCh38.dna.chromosome.15.fa.gz`), plus the soft-masked version for the
  k-mer reference. Build the minimap2 `sr` index: `minimap2 -x sr -d ref/chr15.sr.mmi ref/chr15.fa`.
- Network access to `rest.ensembl.org` (gene coordinates + VEP annotation).

Typical run:
```bash
zcat data/WGS_EX2312012_HGWCNDSX7.vcf.gz | python analisis/extraer_todo.py analisis/out
python analisis/01_cnv_baf.py        data/WGS_EX2312012_HGWCNDSX7.vcf.gz  analisis/out/cnv_baf
python analisis/02_genes_candidatos.py data/WGS_EX2312012_HGWCNDSX7.vcf.gz analisis/out/genes
python analisis/03_bub1b_workup.py   data/WGS_EX2312012_HGWCNDSX7.vcf.gz
bash   align/extraer_bub1b.sh                       # bbduk + minimap2 -> align/bub1b.bam
python align/05_analisis_bam.py                     # -> align/RESULTADO_fase2.txt
```

## Data handling

This repository contains **code and the public submission deliverables only**. It does **not**
contain the controlled-access dataset, aligned reads, or per-position genotype output files —
those are regenerated by running the pipeline with dataset access. Under the hackathon rules the
dataset must be deleted within 30 days of the hackathon close.
